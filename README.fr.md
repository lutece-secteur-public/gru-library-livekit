# Library LiveKit

## Introduction

Cette librairie intègre le serveur de visioconférence [LiveKit](https://livekit.io/) àLutece via l'interface `IVirtualMeetingProvider` définie par le module `module-appointment-virtualmeeting` .

Elle fournit les fonctionnalités suivantes :

 
* Génération de jetons JWT pour les participants (publication +écoute) et les spectateurs (écoute seule)
* Création et suppression de salles via l'API LiveKit Server
* Gestion des participants (liste, détail, suppression)
* Miseàjour des métadonnées d'une salle
* Génération d'URL de réunionàpartir d'un patron d'URL configurable

## Configuration

Configurez la librairie dans le fichier `WEB-INF/conf/plugins/livekit.properties` :

| Propriété| Description| Valeur par défaut|
|-----------------|-----------------|-----------------|
|  `livekit.server.apiKey` | Cléd'API LiveKit| (obligatoire)|
|  `livekit.server.apiSecret` | Secret d'API LiveKit| (obligatoire)|
|  `livekit.server.url` | URL du serveur LiveKit|  `http://localhost:7880` |
|  `livekit.server.token.ttl` | Durée de validitédes jetons en secondes|  `21600` (6 heures)|
|  `livekit.server.meetingUrlPattern` | Patron d'URL de l'application front-end LiveKit. Les marqueurs `{room}` et `{token}` sont remplacésàl'exécution.|  `https://meet.example.com/?room={room}&token={token}` |

## Utilisation

Ajoutez la dépendance Maven dans le POM de votre site :
<dependency><groupId>fr.paris.lutece.plugins</groupId><artifactId>library-livekit</artifactId><version>1.0.0-SNAPSHOT</version><type>lutece-plugin</type></dependency>
La librairie est automatiquement détectée en tant que `IVirtualMeetingProvider` par le module `module-appointment-virtualmeeting` via la découverte de beans Spring. Aucun câblage supplémentaire n'est nécessaire.

Lorsque `VirtualMeetingService` appelle `getParticipantMeetingUrl()` ou `getViewerMeetingUrl()` , le fournisseur LiveKit génère un jeton JWT et l'insère dans le patron d'URL configuré, retournant un lien de réunion prêtàl'emploi.
