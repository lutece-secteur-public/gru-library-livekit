# Library LiveKit

## Introduction

This library integrates the [LiveKit](https://livekit.io/) video-conferencing server with Lutece through the `IVirtualMeetingProvider` interface defined by the `module-appointment-virtualmeeting` module.

It provides the following features:

 
* JWT token generation for participants (publish + subscribe) and viewers (subscribe only)
* Room creation and deletion via the LiveKit Server API
* Participant management (list, get, remove)
* Room metadata update
* Meeting URL generation from a configurable front-end URL pattern

## Configuration

Configure the library in the file `WEB-INF/conf/plugins/livekit.properties` :

| Property| Description| Default|
|-----------------|-----------------|-----------------|
|  `livekit.server.apiKey` | LiveKit API key| (required)|
|  `livekit.server.apiSecret` | LiveKit API secret| (required)|
|  `livekit.server.url` | LiveKit server URL|  `http://localhost:7880` |
|  `livekit.server.token.ttl` | Token time-to-live in seconds|  `21600` (6 hours)|
|  `livekit.server.meetingUrlPattern` | URL pattern for the LiveKit front-end application. The placeholders `{room}` and `{token}` are replaced at runtime.|  `https://meet.example.com/?room={room}&token={token}` |

## Usage

Add the Maven dependency to your site POM:
<dependency><groupId>fr.paris.lutece.plugins</groupId><artifactId>library-livekit</artifactId><version>1.0.0-SNAPSHOT</version><type>lutece-plugin</type></dependency>
The library is automatically discovered as an `IVirtualMeetingProvider` by the `module-appointment-virtualmeeting` module through Spring bean detection. No additional wiring is required.

When `VirtualMeetingService` calls `getParticipantMeetingUrl()` or `getViewerMeetingUrl()` , the LiveKit provider generates a JWT token and embeds it into the configured URL pattern, returning a ready-to-use meeting link.
